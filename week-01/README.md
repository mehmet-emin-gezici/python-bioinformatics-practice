# Week 1: DNA toolkit, part 1

A small Python module (`dna_tools.py`) with four functions for working
with DNA sequences, written using strings and functions only.

| Function | What it does | Rosalind problem |
|----------|--------------|------------------|
| `count_bases(seq)` | Counts how many A, C, G and T bases a sequence contains | DNA |
| `transcribe(seq)` | Converts DNA to RNA by replacing T with U | RNA |
| `reverse_complement(seq)` | Reverses the sequence and swaps A with T and C with G | REVC |
| `gc_content(seq)` | Returns the percentage of bases that are G or C | GC (core calculation) |
